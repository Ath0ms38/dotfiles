# Fastfetch Configuration

Fastfetch config themed to follow the current wallpaper.

`config.jsonc` is **generated by matugen** from the template at
`matugen/.config/matugen/templates/fastfetch.jsonc` — edit the template, not
the output file, or your changes will be overwritten on the next wallpaper
change.

## Files

```
fastfetch/
└── .config/
    └── fastfetch/
        └── config.jsonc   # generated by matugen (do not edit directly)
```

## Installation

```bash
stow fastfetch
```

## Usage

```bash
fastfetch
```

Requires a Nerd Font (JetBrainsMono Nerd Font recommended) for the icons.
