# Dotfiles

Everything under `~/dotfiles` is a set of **GNU stow packages**. A package
directory mirrors `$HOME`, so the real config path is:

```
~/dotfiles/<package>/.config/<app>/…   →   ~/.config/<app>/…
```

The files in `~/.config` are **symlinks into the repo**. Editing either path
edits the same file — but always talk about the repo path, and never replace
a symlink with a regular file (that silently detaches it from the repo).

## Never hand-edit generated files

Theme colours are generated by matugen on every wallpaper change. Any file
marked as generated (`colors.css`, `colors.conf`, `colors.rasi`, …) is
overwritten. Edit the templates instead:

```
~/dotfiles/matugen/.config/matugen/templates/
```

## Secrets

The repo is **public**. API keys live in `~/.config/nova/secrets.env`, which
is excluded by a `.gitignore` inside the stow package itself. Never print a
key, never commit one, never move one out of that file.

## Rules

- New config file for a stowed app → create it in the repo package, then
  re-run `stow` from `~/dotfiles`; do not create it directly in `~/.config`.
- `hyprland/.config/hypr/conf/rules.conf` must be kept in sync by hand with
  the workspace assignments in `~/.config/fabric/config.json`.
- Committing or pushing is the user's call — ask first.
