# dotfiles

Arch Linux + Hyprland desktop, with a custom status bar and "notch" built on
[Fabric](https://github.com/Fabric-Development/fabric), themed automatically
from the current wallpaper via [matugen](https://github.com/InioX/matugen).

## Install (fresh machine)

```bash
git clone <this-repo> ~/dotfiles
cd ~/dotfiles
./bootstrap.sh
```

`bootstrap.sh` installs pacman/AUR packages, oh-my-zsh + plugins, links every
config with GNU stow, creates the fabric Python environment with uv, installs
the SDDM login theme (`/etc/sddm.conf` + theme symlink into `/usr/share`),
and enables system services. Pre-existing configs are backed up to
`~/dotfiles-backup-<date>/`.

## Layout

Each top-level directory is a stow package mirroring `$HOME`:

| Package     | What it is                                                        |
|-------------|-------------------------------------------------------------------|
| `hyprland`  | Hyprland config (`conf/*.conf`), hyprlock, hypridle, hyprpaper    |
| `fabric`    | Status bar + notch (Python, uv-managed venv, see below)           |
| `matugen`   | Wallpaper→theme pipeline: templates + post-hook script            |
| `kitty`     | Terminal                                                          |
| `zsh`       | Shell (oh-my-zsh + starship)                                      |
| `rofi`      | Launcher + menus                                                  |
| `swaync`    | Notifications                                                     |
| `starship`  | Prompt (generated by matugen)                                     |
| `fastfetch` | System info (generated by matugen)                                |
| `openclaw`  | Nova ✨ AI agent: voice, scripts, services (see its README)        |
| `sddm`      | Login screen theme (installed to `/usr` via `sddm/install.sh`)    |
| `wallpapers`| Wallpaper collection (referenced by absolute path)                |

Link one package manually with `stow <package>` from the repo root.

## Theming pipeline (matugen)

Picking a wallpaper (fabric's wallpaper widget or `set-wallpaper.sh <path>`)
generates colors for every app from the templates in
`matugen/.config/matugen/templates/`, then `post-matugen.sh` sets the
wallpaper and live-reloads Hyprland, kitty, swaync and the fabric bar.

**Edit the templates, not the generated files.** Generated files include
`hypr/conf/colors.conf`, `fabric/colors.css`, `kitty/colors.conf`,
`fastfetch/config.jsonc`, `starship.toml`, rofi/swaync/sddm colors.
The lock screen (`hyprlock.conf`) sources `conf/colors.conf`, so it follows
the theme automatically.

### Wallpapers: images and videos

`matugen/.config/matugen/set-wallpaper.sh` is the single entry point and picks
the backend from the file extension:

| Wallpaper                            | Displayed by | Colors generated from |
| ------------------------------------ | ------------ | --------------------- |
| `png jpg jpeg bmp gif webp`          | hyprpaper    | the image             |
| `mp4 mkv webm mov avi m4v`           | mpvpaper     | its first frame       |

Since matugen and hyprlock only read images, a video is tracked as two paths in
`~/.cache/wallpaper/state`: the *source* (what plays on screen) and the *still*
(first frame, extracted with ffmpeg and cached in `~/.cache/wallpaper/frames/`).
The still feeds the palette, the lock screen background and the fabric
thumbnails; the fabric widget reuses the same cache, so each video is decoded
once. `restore-wallpaper.sh` replays the right backend at login.

```bash
set-wallpaper.sh ~/dotfiles/wallpapers/city.mp4          # video + new theme
set-wallpaper.sh ~/dotfiles/wallpapers/city.mp4 -t scheme-expressive
set-wallpaper.sh ~/dotfiles/wallpapers/room.png --no-matugen  # keep colors
set-wallpaper.sh                                         # rofi picker
```

mpvpaper runs mpv continuously — expect real battery cost on a laptop. It is
started with `-p`, which pauses decoding under a fullscreen window.

## Fabric bar

Two apps in `fabric/.config/fabric/`: `fabric-bar.py` (status bar) and
`ax_notch_bar.py` (notch + dashboard). Dependencies are declared in
`pyproject.toml` and locked in `uv.lock`; `restart.sh` creates the venv with
`uv sync` if missing, then (re)starts both bars.

App/workspace assignments (Discord, VS Code, Minecraft, Steam…) live in
`config.json` under `special_workspaces` — single source of truth used by the
bar buttons, `toggle_app.py`, and the workspace manager. Window rules in
`hypr/conf/rules.conf` must be kept in sync manually.

## Lock screen

`hyprlock` (Super+L, or automatically via `hypridle` after 5 min idle;
suspend after 30 min). Config: `hyprland/.config/hypr/hyprlock.conf`.
